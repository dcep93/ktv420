# KTV420 Frontend

React/Vite frontend for KTV420.

## Commands

- `npm run dev`: start the local Vite dev server.
- `npm run build`: type-check and build the production bundle.
- `npm run lint`: run ESLint.
- `npm run preview`: preview the built bundle.

## Source Layout

The app source lives in `src/` and is organized by responsibility:

- `app/`: application wiring, including route definitions.
- `pages/`: route entry components.
- `features/`: feature and domain implementation code used by pages.

See `src/README.md` for the detailed source layout rules.
