GET STARTED

Install once. Keep your music local.

  1. Download and unzip

    Extract ktv420-extension.zip into a folder you intend to keep. No Docker, terminal commands or local server needed.

  2. Load it in Chrome

    Open chrome://extensions, switch on Developer mode, choose Load unpacked, then select the extracted folder containing manifest.json.

  3. Open your library

    Pin ktv420 in Chrome’s extensions menu, then click its icon. Drop in an audio file and select Separate. The first run downloads a full-precision Demucs model (about 181 MB); it is kept locally for future offline use.

  4. Make it yours

    Adjust the four stems, add effects, switch visualizers and export WAV files. Keep the library tab open while separation runs. If interrupted, reopen it and retry; saved inputs and completed tracks remain available.

Capture from Spotify

Open a playlist or album at open.spotify.com. Use the ktv420 capture panel, keep Spotify open, and let the tracks play. Captures appear in your extension library. Capture is in real time; seeking or changing tracks interrupts it.

After installing or updating the extension, reload Spotify so its capture controls can load.

Precision, with room to grow

Audio is never uploaded. Original WAV files are preserved. Capture and stems are stored as Float32, without added MP3 encoding or clipping. Separation itself changes audio; source compression and necessary sample-rate conversion are not reversible.

Allow roughly 424 MB per four-minute track for a Float32 original plus four stems, before any additional source file. Files stay in this Chrome profile. Uninstalling the extension removes its library, so export files you want to keep.

GPU when available

ktv420 prefers WebGPU, including Apple Silicon GPUs in current Chrome. A CPU compatibility option is available. Actual speed depends on the computer, browser and track; model setup can take time on the first run.

Chrome 121 or newer is required; use the latest stable Chrome. This release is for desktop computers.

Updating

Download the new ZIP, close ktv420, replace the files in the same extension folder, and click Reload at chrome://extensions. Keep the same installation and Chrome profile to retain your library.
